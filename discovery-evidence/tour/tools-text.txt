generate_image

Generate ONE image from a text prompt and show it in the chat with a download link. COSTS money per image from the user's wallet (draft is cheaper than final), so call it only when the user actually asked for an image — never speculatively or to illustrate your own explanation. Repeating an identical prompt is free. To make a DIFFERENT version of the same idea, pass a new `seed`.

sql_query
sandboxed

Run a READ-ONLY SQL query (SELECT / WITH / PRAGMA) against a SQLite file or CSV the user has saved in their own storage (loaded as table 'data' for CSV). Use it to analyse uploaded data files. Returns up to 200 rows as text.

run_python
sandboxed

Execute a short Python snippet in an isolated sandbox (20s timeout, 256 MB cap, no network, no host filesystem). Use it for quick calculations, parsing, or small scripts. Remember to print() what you want to see.

draft_project_plan

propose_project_setup

Persist a complete, structured Setup Proposal for the CURRENT project once you have interviewed the user and the goal is crystal clear. This does NOT create agents, bind skills, or run anything — it records a proposal the user reviews and Applies. Requires an active project.
